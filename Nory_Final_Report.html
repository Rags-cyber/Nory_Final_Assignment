1. Introduction / Project Plan

1.1 Project Overview

Nory is a web-based Learning Management System designed for students who want to learn music theory and beginner guitar skills in one structured environment. The application provides self-paced lessons, theory and ear-training quizzes, a guitar chord and song library, progress tracking, awards, and role-based dashboards. It also gives administrators and instructors the tools needed to maintain learning content and user records.

The project uses ASP.NET Core Razor Pages, C#, Entity Framework Core, Microsoft SQL Server, HTML5, CSS3, and JavaScript. The application is connected to a relational database called Nory and demonstrates authentication, authorization, database CRUD operations, client-side and server-side validation, multimedia playback, and responsive interface design.

1.2 Objectives

  • Deliver a secure and responsive music learning platform for students.
  • Provide structured music-theory lessons and beginner guitar content.
  • Provide theory quizzes and interactive ear-training activities.
  • Track lesson completion, quiz scores, and student progress.
  • Award badges or achievements when students complete meaningful activities.
  • Support Student, Instructor, and Administrator role-based access.
  • Demonstrate complete database CRUD functionality and reliable SQL Server connectivity.

1.3 Project Scope

The system includes public navigation, student registration and login, student learning features, instructor management features, and an administrator module. Public visitors can browse general information and open the registration page. Students can enrol in courses, read lessons, complete quizzes, view their dashboard, track progress, and update their profiles. Instructors can manage their courses and lessons. Administrators can manage users, courses, lessons, quizzes, quiz questions, resources, and general content.

The scope covers music theory for beginners, basic guitar skills, note reading, major scales, intervals, triads, chord progressions, ear training, and song chords. Live video conferencing, mobile applications, offline learning, and artificial-intelligence recommendations are outside the current scope.

2.3 Flow Chart and Major Functions

The main student flow begins at the public home page. The visitor registers, signs in, and is redirected to the Student Dashboard. From there the student browses courses, enrols, opens lessons, completes a lesson, takes a quiz, and receives a score. Successful scores update the quiz attempt history and may generate an award. The admin flow begins at login, continues to the Admin Dashboard, and branches into user, course, lesson, quiz, resource, and question management. Each management branch uses database CRUD operations.

Major functions include:

  • Role-based authentication and authorization.
  • Student enrolment and progress tracking.
  • Lesson delivery with text, media, resources, and completion tracking.
  • Theory, note-reading, chord-shape, and ear-training quizzes.
  • Audio synthesis for ear-training questions using the Web Audio API.
  • Guitar song and chord library.
  • Awards and quiz result history.
  • Instructor and administrator CRUD modules.
  • Profile management stored in the AspNetUsers table.

4. Implementation

4.1 Application Architecture

The solution uses ASP.NET Core Razor Pages. Page models retrieve and update data through Entity Framework Core and the ApplicationDbContext class. The Student, Instructor, and Admin areas separate pages by role. Shared layout files provide common navigation, while area-specific pages contain feature logic.

4.2 HTML5 Elements

The application uses semantic HTML5 structure and Bootstrap markup. Examples include <header>, <nav>, <main>, <footer>, <section>, <article>, <form>, <input>, <select>, <textarea>, <audio>, <video>, <svg>, and responsive grid classes. Lesson media uses <audio> and <iframe> elements. Quiz visuals use inline SVG for the music staff and guitar chord diagrams.

4.4 Form Validation

The registration and profile forms use Data Annotations for server-side validation. ASP.NET also renders client-side validation through jQuery Validation. Required fields, email format, password length, password comparison, phone number format, and date input are validated. Quiz submission also validates that every question receives an answer before the attempt is scored.

[Required, StringLength(50)]
[Display(Name = "First name")]
public string FirstName { get; set; } = "";

[Required, DataType(DataType.Password)]
[StringLength(100, MinimumLength = 6)]
public string Password { get; set; } = "";

[Required, DataType(DataType.Password)]
[Compare(nameof(Password), ErrorMessage = "The passwords do not match.")]
public string ConfirmPassword { get; set; } = "";

4.5 Database Connectivity and SQL

The application uses Entity Framework Core with a SQL Server connection string in appsettings.json. Nory_Database_Script.sql creates the Nory database and tables. Nory_Upgrade_Existing_Database.sql upgrades older databases with resources, completions, awards, chords, tone sequences, and profile columns. Nory_Local_Content_And_Chords.sql inserts self-contained lesson content, quizzes, and song chords.

Typical CRUD operations are implemented with Entity Framework Core queries such as:

// Display
var courses = await _context.Courses
    .Include(c => c.Lessons)
    .ToListAsync();

// Insert
_context.Courses.Add(course);
await _context.SaveChangesAsync();

// Update
_context.Entry(course).State = EntityState.Modified;
await _context.SaveChangesAsync();

// Delete
_context.Courses.Remove(course);
await _context.SaveChangesAsync();

4.6 Authentication and Authorization

ASP.NET Core Identity stores hashed passwords, security stamps, and role assignments. Roles are created on startup. Public self-registration always creates a Student account; Instructor and Admin accounts are assigned by an administrator. Area authorization is configured in Program.cs.

builder.Services.AddRazorPages(options =>
{
    options.Conventions.AuthorizeAreaFolder("Admin", "/", "Admin");
    options.Conventions.AuthorizeAreaFolder("Instructor", "/", "Instructor");
    options.Conventions.AuthorizeAreaFolder("Student", "/", "Student");
});

4.7 Quizzes, Ear Training, and Awards

Each quiz attempt stores the student, quiz, start and completion time, score percentage, and pass status. Each answer stores the selected response, correctness, points earned, and feedback. Ear-training questions can play synthesized frequencies using the Web Audio API, so no external audio file is required. Note-reading questions render an SVG staff, and chord-shape questions render a fretboard diagram.

A successful attempt can generate a one-time award through the StudentAwards table. Awards are keyed by student and award key so the same award is not duplicated.

4.8 Profile Management

The profile page shows common account details and role-specific sections. Students can edit instrument, skill level, and learning goals. Instructors can edit teaching specialty and years teaching. Administrators can edit department and job title. The fields are stored directly in dbo.AspNetUsers and only the fields matching the signed-in user's role are written.

5. User Guidance

5.1 Student Usage

  1. Open the Home page and select Sign In or Start Learning Free.
  2. Create a new student account using a valid email and password.
  3. Sign in and go to Student Portal > My Dashboard.
  4. Select Browse Courses, choose a course, and select Enroll Now.
  5. Open a course and start a lesson.
  6. Read the lesson sections, examples, and resources, then select Mark Lesson Complete.
  7. Open the lesson quiz, answer every question, and select Submit Quiz.
  8. Review the score, pass status, and feedback on the result page.
  9. Use Theory & Ear Training to practise note, chord, and listening quizzes.
  10. Use Guitar Song Chords to find song lyrics and chord progressions.
  11. Use My profile to update contact details and student learning preferences.

5.2 Instructor Usage

  1. Sign in with an instructor account.
  2. Open Instructor Console > Dashboard.
  3. Select My Courses to manage assigned courses.
  4. Insert, update, or remove lessons using the instructor lesson pages.
  5. Review lesson content and ensure quizzes are active for students.

5.3 Administrator Usage

  1. Sign in with an administrator account.
  2. Open Admin Console > Dashboard.
  3. Use Courses, Lessons, Quizzes, Resources, and Quiz Questions to manage learning content.
  4. Use User Management to inspect, update, or remove users.
  5. Verify records in the SQL Server database after major CRUD operations.

6. Conclusions

6.1 Summary

Nory successfully provides an integrated web-based learning platform for music theory and beginner guitar. It includes role-based authentication, structured lessons, quizzes, ear training, chord songs, progress tracking, awards, profile management, and full database-backed administration. The application demonstrates client/server processing, SQL Server connectivity, CRUD operations, multimedia, validation, and responsive design.

6.2 Lessons Learned

The project improved understanding of ASP.NET Core Razor Pages, Entity Framework Core, SQL Server schema management, Identity security, and role-based authorization. It also highlighted the importance of validating user input at both client and server levels, organizing pages by role, and keeping database scripts synchronized with entity models. Handling real browser behaviour, such as audio playback and quiz form submission, required careful testing and defensive validation.

6.3 Future Enhancements

  • Live online classes and instructor messaging.
  • More advanced ear-training modes and adaptive difficulty.
  • Uploaded audio and sheet music with file management.
  • Instructor analytics on class performance.
  • Mobile application support.
  • AI-assisted lesson recommendations.
  • Integration with payment or certificate-generation services.
