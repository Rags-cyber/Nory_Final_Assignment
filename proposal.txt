
Nory – Music Learning Platform
Nory: Music Learning Platform is an online learning website, which offers an interactive and systematic learning curve for any music theory fan or anyone who wants to learn the basics of guitar. The platform combines theoretical teaching with learning the instruments interactively, enabling users to enhance their musical skills through interactive lessons, quizzes, and progress monitoring.
Learners then complete quizzes and access learning materials and can track their learning through an individualised dashboard, all while having access to the interface with security provided by the system itself. Put complete CRUD (Create/Read/Update/Delete) abilities for lessons, quizzes, users, and educational material to put it to use efficiently within a secure administration center. The platform is created using ASP.NET Web Forms, Microsoft SQL Server, HTML5, CSS3 and JavaScript.
1. Introduction
The development of web technologies has enabled a change in the entire education field delivering flexible, accessible learning to pupils via online means. Today's student is no different and for music education for instance, there are various but increasing numbers of students who want to learn at their own rate and in their own pace – on a computer platform and on their own devices. Most studies on the subject of music in the beginning are also disconnected from the playing of an instrument and teach music theory and not how it relates to the practical application of playing the instrument.

Nory: Music Learning Platform aims to solve this problem by trying to combine music theory with learning the basics of the guitar into a single online programme. Learners can sign up, discover structured lessons, take quizzes and keep track of their learning journey using their own learning tracking dashboard. The platform allows a development of a learning environment that's engaging and organized, with the potential of self-paced learning.

Developed the system with the use of ASP.Use C#, HTML5, CSS3 and JavaScript to write web applications in the.NET Core MVC framework, and use Microsoft SQL server to create and manage a relational database. It includes authentication, authorization, CRUD operations, responsive web design, client side validation and server side validation, as well secured database management system to achieve a reliable and effective learning experience.

2. Objectives

The main objectives of the project are:
To create a safe and responsive music theory and guitar beginner's learning website.
To secure users' registration and login/access control in learners and administrator.
To give administrators a centralized dashboard to manage lesson, quiz, user and educational content with various CRUD operations.
To enable integration of Microsoft SQL Server for secure storing and efficient management of user, lesson and quiz information.
To facilitate interactive and user friendly learning with structured lesson plans, quiz questions, tracking system, and a responsive design.

2.1 Mission Statement
The goal of Nory is to offer a welcoming, educational and safe web based learning setting for anybody to start development of music theory information and guitar beginner abilities utilizing interactive lessons, sensible schooling activities and tailored progress monitoring. As a new platform, it aims to provide an innovative online learning environment with leading-edge Web capabilities that facilitate ongoing learning and musical growth.

4. Problem Statement and Proposed Solution
4.1 Problem Statement
Beginners have problems learning music due to the large number of educational sites and applications, which are not consolidated in a single place. Music theory and the practical lessons of playing the guitar are rarely intertwined, which can make it hard for the student to relate theory to the actual playing. Also, most of the stage are suffering from the absence of structured learning trajectories, progression checking, and also advantageous material supervisory tools.

These constraints make learning less engaging, and impede administrators from having current up-to-date educational resources.

4.2 Proposed Solution
Nory has as aim to create a concentrated web learning environment for Music Theory and beginner guitar lessons. The users can safely enroll, sign in, reach lessons, do quizzes and observe learning progress on a personalized Board based coming from the teacher.

Administrators have full CRUD (Create, Read, Update, Delete) access to lessons, quizzes, users and educational content in a secure administration panel. The site is powered by ASP.To deliver a secure authentication system, effective database management using NET Core MVC along with C, Entity Framework Core and Microsoft SQL Server, responsive web design, and scalable system architecture.
